# Сворм понимает, какой агент во вкладке — Implementation Plan

> **Статус: РАЗВЕДКА, не к исполнению.** Факты собраны 2026-09-21, решение отложено
> («позже покопаем»). Порядок работ ниже намеренно запрещает начинать с абстракции.

**Goal:** Сворм перестаёт быть надстройкой над Claude Code и становится пультом над роем,
безразличным к тому, кто в рое сидит. Вкладки на разных агентах — в одном окне, с общими
дайджестами, перезапуском, телеграмом и голосом.

**Повод:** доступ к Anthropic для владельца под вопросом (баны аккаунтов из РФ). Запасной
харнесс — Codex CLI с GPT-6 Astra.

---

## Что уже выяснено (не переисследовать)

### Харнесс ≠ модель

Сворм видит ХАРНЕСС (TUI, хуки, файлы сессий), а не модель. Отсюда:

- `claude-glm`, `cld` и прочие обёртки через `ANTHROPIC_BASE_URL` — это **Claude Code**.
  Переезд на GLM / Kimi / MiniMax не требует от сворма ни строчки.
- Адаптер нужен только для смены харнесса: Claude Code → Codex CLI.

### Хуки Codex: их БОЛЬШЕ, чем у Клода

Codex регистрирует 12 событий (с 0.150.1, конец августа 2026), включены по умолчанию.
Конфиг: `~/.codex/hooks.json` или инлайн `[[hooks.PreToolUse]]` в `config.toml`.
Работают только `command`- и MCP-обработчики (prompt/agent парсятся и игнорируются) — нам
нужны как раз `command`.

| Наше событие (`hook-config.js`) | В Codex |
|---|---|
| `UserPromptSubmit` | то же имя |
| `Stop` | то же имя |
| `PreToolUse` | то же имя |
| `PostToolUse` | то же имя |
| `SessionStart` | то же имя |
| `PermissionRequest` | **есть отдельным событием** |
| `Notification` (nag / lull) | **аналога нет**; легаси `AfterAgent`/`AfterToolUse` устарели |

Сверх наших семи: `SubagentStart`, `SubagentStop`, `Interrupt`, `PreCompact`, `PostCompact`,
`SessionEnd`. Payload хука: `session_id`, `turn_id`, `cwd`, `hook_event_name`, `model`,
`permission_mode`.

### Статуслайн: свой скрипт подсунуть НЕЛЬЗЯ, и он не нужен

- `tui.status_line` — упорядоченный список ПРЕДОПРЕДЕЛЁННЫХ идентификаторов, не команда.
  Command-backed statusline: #20140 закрыт как дубль, головной #17827 открыт с апреля
  (46 комментариев, шевелился 2026-09-15). Не сделано.
- Но Codex НАТИВНО печатает в футере то, ради чего написан `swarm-statusline.js`: процент
  контекста (`Context 82% left`, можно баром) плюс остаток 5-часового и недельного лимита.
  Настройка: `/statusline` или `[tui] status_line`.
- Следствие: `swarm-statusline.js` (418 строк) не переписывается, а **удаляется**.
  Скрейпинг «NN%» из строки остаётся как есть — строку теперь рисует сам агент.
- **Самоперезапуск по порогу контекста выживает.** Это был главный риск.

### Ответ на разрешение переживает переезд

Сворм отвечает печатью в pty (`pty-write.js`), кнопки несут варианты самого агента —
механизм агентно-независимый. Но ЧИТАЕТ варианты `screen.js`, он переписывается всё равно.

`permissionDecision: "ask"` (эскалация из `PreToolUse` в нативный запрос) ещё не сделана
(#28437 открыт). Нам не нужна: запрос надо НАБЛЮДАТЬ, для этого есть `PermissionRequest`.

## Architecture

### Как узнаём, кто во вкладке

Не спрашивать человека и не гадать по команде — доктрина уже записана в `subs.js`:
догадка по стему врёт ровно в интересных случаях.

Готовый образец механики — `learnHome` (`subs.js:138`): карточка не объявляет свой конфиг,
а узнаёт его из первого снимка расхода. Так же и здесь: **`learnKind` рядом с `learnHome`,
поле `kind` в карточке рядом с `home`**. Опознание — по payload первого сработавшего хука
(у Клода и Codex наборы полей разные, спутать нельзя).

До первого сигнала вкладка живёт в нейтральном режиме: pty работает, статус «неизвестно» —
ровно как сейчас карточка без пилюли, пока не пришли числа.

### Семь слотов адаптера

| Слот | Claude Code | Codex | Судьба |
|---|---|---|---|
| строка запуска | `--settings`, `--append-system-prompt`, `--permission-mode` | `config.toml`, `-c` | `launch-line.js` 105 — механически |
| имена событий | 7 своих | 12 своих, 6 совпадают | `hook-config.js` 28 — переименовать |
| разбор payload | `swarm-signal.mjs` | он же, другая ветка | 1010 — ветка |
| чтение экрана | `screen.js` + `ask-phrases.js` | **заново** | 796 + 333 |
| машина статуса | `detector.js` | **заново** | 625 |
| чтение транскрипта | `~/.claude/projects/*.jsonl` | `~/.codex/sessions/*` | 402 — заново |
| источник расхода | `rate_limits` + свой статуслайн | нативный футер | `subs.js` 483 — упростить |

Ядро настоящей работы — **~2 150 строк** (экран + детектор + транскрипт), а не 4 255.

### Что уже агентно-независимо и не трогается

pty и вкладки, рендерер, дайджесты, перезапуск, телеграм, голос, ночной мандат, реестр
соседей, git, апдейтер. Они разговаривают со ВКЛАДКОЙ, а не с Клодом.

## Порядок работ (важнее самих работ)

**НЕ проектировать адаптер до того, как заработает вторая реализация.** Интерфейс,
спроектированный по одному известному случаю, оказывается формой этого случая.

- [ ] **Шаг 0 — собрать фикстуры, ПОКА ДОСТУП К КЛОДУ ЕСТЬ.** Поставить Codex CLI и снять
      экраны в состояниях: работает / ждёт разрешения / задал вопрос / готов / прервано.
      Это тот материал, по которому `detector.js` дальше пишется механически. Без него шаг 2
      превращается в гадание.
- [ ] **Шаг 1 — заставить Codex работать КОНКРЕТНО.** Грязно, ветками `if` прямо в `main.js`.
      Цель — рабочая вкладка, а не красивый код.
- [ ] **Шаг 2 — экран и детектор под TUI Codex.** По фикстурам шага 0, тем же методом:
      снимок → чистые функции → тесты на фикстурах.
- [ ] **Шаг 3 — транскрипт.** Формат `~/.codex/sessions/*` вместо `projects/*.jsonl`.
- [ ] **Шаг 4 — удалить `swarm-statusline.js` на ветке Codex, упростить `subs.js`.**
- [ ] **Шаг 5 — и только теперь вынести шов.** `learnKind`, поле `kind`, семь слотов.
      Шов к этому моменту проявится сам, по факту двух живых реализаций.

Потери при переезде: только `Notification` (напоминания nag / lull) — самое мелкое из семи.
